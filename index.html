🐙 مرحلهٔ ۱ — اتصال به گیت‌هاب

سلف‌بات روی GitHub Actions اجرا می‌شه — رایگان و ۲۴ ساعته. برای این کار یه «توکن دسترسی» می‌خوایم:

  1. روی دکمهٔ زیر بزن تا صفحهٔ ساخت توکن باز بشه (دسترسی‌هاش خودکار انتخاب شده)
  2. ته صفحه روی Generate token کلیک کن
  3. کدی که سبزه (ghp_…) رو کپی کن و اینجا بذار
🔓 ساخت توکن در گیت‌هاب
👁 نمایش
📦 مرحلهٔ ۲ — ساخت مخزن

یه کپی از سلف‌بات روی اکانت گیت‌هابت می‌سازم و اجرای خودکارش (Actions) رو فعال می‌کنم.

📱 مرحلهٔ ۳ — ورود به تلگرام

با اکانت خودت وارد می‌شم تا «کلید نشست» ساخته بشه — همون چیزی که سلف‌بات باهاش به‌جای تو آنلاین می‌مونه.

🌐 اتصال مستقیم به سرور تلگرام — رمز و کد به هیچ جای دیگه نمی‌ره.
📩 کد ورود به تلگرامت فرستاده شد (به اپ جدیدی که لاگینه — نه SMS).
🔐 اکانتت رمز دوم (۲FA) داره.

🤖 مرحلهٔ ۴ — بات مدیریت

یه بات شخصی می‌سازم که سلف‌باتت رو از تلگرام کنترل کنی — منو فارسی، دکمه‌ها، همه‌چیز. با BotFather خودکار ساخته می‌شه.

یادت باشه بات‌ها عمومی‌ان — هر کسی آیدیش رو داشته باشه می‌تونه پیام بده؛ ولی فقط تو می‌تونی دستور بدی.

⚠️ سه قانون طلایی
  • تو Settings → Devices هیچ‌وقت session رو terminate نکن — اون «Telegram Desktop» با IP خارجی که می‌بینی خود سلف‌باته، نفوذگر نیست!
  • تو تب Actions مدام اجرا می‌بینی — طبیعیه؛ هر ~۶ ساعت یه شیفت تازه برای ۲۴/۷ موندن.
  • برای خاموش‌کردن موقت: مخزن → Settings → Actions → Disable. برای برگشتن همون‌جا Enable.
