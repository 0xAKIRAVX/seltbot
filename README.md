# 🤖 SeltBot v2.8 — سلف‌بات کامل تلگرام

سلف‌بات ماژولار روی **اکانت خودت** (Telethon userbot) — بدون ترموکس، اجرای ۲۴/۷ روی GitHub Actions، با طراحی **ضدبن**.

**v2.8.0 جدید (شکار باگ بزرگ):** ماشین‌حساب امن در برابر قفل‌شدن (9**9**9 دیگه هنگ نمی‌کنه) + اعتبارسنجی `.set` (مقدار خراب دیگه ساعت رو نمی‌کشه) + ضد-اسپمِ پولینگ بات مدیریت + یادآور تکراری بعد از قطعی فقط یک‌بار می‌فته + مسیر امن فایل نوت‌ها + رفع بیو خالی در `.info` و خطای `.common` + نصب وابسته‌های اختیاری جدا-جدا.

## 🚀 استفاده (۵ ثانیه)

هر چیزی که می‌خوای رو توی تلگرام از **اکانت خودت** بفرست (بهترین جا: **Saved Messages / پیام‌های ذخیره‌شده**):

```

```

(اول یه بار بازش کن و START بزن.)

## 🕐 ساعت زنده

پیش‌فرض: `اسم اول شما ｜ 𝟶𝟺:𝟺𝟻` — هر دقیقه، دقیق با ساعت گوشی (Asia/Tehran)، ارقام مونو.


## 🧩 قوانین اگر-آنگاه (IF-THEN)

هر اتفاقی → واکنش خودکار. ساختار: `.rule add <اگر>:<مقدار> -> <آنگاه>:<مقدار>`

```
.rule add kw:سلام -> reply:سلام علیکم          ← اگه کلمه‌ای گفته شد
.rule add re:^\?+ -> reply:واضح‌تر بپرس          ← رجکس
.rule add from:123456789 -> reply:الان نمی‌تونم  ← پیامِ کاربر خاص
.rule add media:link -> del                       ← لینک‌ها حذف شن (ادمین)
.rule add media:sticker -> react:❤️               ← استیکر → ری‌اکشن
.rule add kw:فوری -> alert:کلمهٔ فوری!            ← هشدار در Saved
.rule add kw:قرارداد -> note:قرارداد              ← ذخیرهٔ خودکار نوت
.rules / .rule del 3 / .rule off / .clearrules
```
تریگرها: `kw` `re` `from` `chat` `media(any/photo/video/gif/sticker/voice/audio/file/link)`
اکشن‌ها: `reply` `del` `react` `alert` `fwd` `note` — سقف ساعتی داره (ضدبن: `.set rules_max_per_hour 25`).

## 🏗 معماری ۲۴/۷ (بدون ترموکس)

- **شیفت‌های ~۵:۴۵ ساعته** روی GitHub Actions (ریپو پابلیک = دقیقه‌های نامحدود رایگان)
- آخر هر شیفت، خودش **شیفت بعدی رو زنجیر می‌کنه** (workflow_dispatch) → قطعی نمی‌شه
- کرون ۳ساعته هم فول‌بکه — اگر زنجیر بشکنه حداکثر ۳ ساعت بعد خودش بالا میاد
- **گارد single-writer**: اگر دو تا ران همزمان بشن، جدیدترین خودش رو می‌بنده (سشن امان می‌مونه)
- وضعیت (نوت‌ها/تنظیمات/آمار) **رمزنگاری‌شده (AES-256) هر ۳۰ دقیقه** توی خود ریپو ذخیره می‌شه (`state.db.enc`) و اول هر شیفت برگردونده می‌شه
- هاست جایگزین بدون وقفه: `Dockerfile` رو بزن روی Render/Koyeb/HF Spaces

## 🛡 چرا بن نمی‌شی؟

- اسم اول هیچ‌وقت دست نمی‌شه، فقط اسم آخر، و فقط وقتی متن واقعاً عوض شه
- کف فاصلهٔ آپدیت ۳۰ ثانیه (پیش‌فرض ۶۰) + هم‌ترازی با دقیقهٔ ساعت
- سقف روزانهٔ آپدیت پروفایل (پیش‌فرض ۱۶۰۰) — پر شد؟ خودکار نگه می‌داره و خبر می‌ده
- FloodWait → backoff نمایی ×۱٫۵ (بعد از ۳۰ دقیقهٔ سالم، آرام برمی‌گرده)
- تشخیص **ریست سایلنت** تلگرام: هر ۵ دقیقه اسم واقعی چک می‌شه؛ اگر تلگرام ریست کرده باشه، دوباره می‌شینه + strike؛ ۳ strike در ساعت = فاصله ×۲
- جواب‌های AFK/پاسخ خودکار: کول‌داون per-user + سقف + تأخیر تصادفی انسانی
- حذف پیام‌ها فقط مال خودت، با فاصلهٔ ۰٫۴ ثانیه
- عکس پروفایل: حداقل ۳۰ دقیقه فاصله

## v2.2 — پنل شیشه‌ای + فیک بحرانی dispatch

**فیک مهم:** ترتیب آرگومان‌های `add_event_handler(callback, event)` در core.py برعکس بود →
هر آپدیتی قبل از رسیدن به هندلرها با `type object 'method' has no attribute 'build'` می‌مُرد →
**هیچ دستوری از اکانت کار نمی‌کرد** (فقط ساعت کار می‌کرد چون تسک مستقل بود). رگرسیون‌تست [10] گاردش می‌کنه.

**ساعت هم‌زمان با گوشی:** نوشتن پروفایل الان دقیقاً ~۰.۳ ثانیه بعد از مرز دقیقه فرود می‌آد
(قبلاً ۱.۲ ثانیه + پولینگ ۱ ثانیه‌ای = تا ۳ ثانیه دیر). حلقهٔ ساعت تا لحظهٔ اکشن بعدی دقیق می‌خوابد.

**پنل شیشه‌ای (bot/menu.py):** `/start` یا `/menu` در بات مدیریت → منوی inline با ۱۳ صفحه و ۴۳ دکمهٔ واقعی.
هر دکمه همان موتور `run_command` را اجرا می‌کند (یک موتور، دو رابط) — پس رفتار دکمه و دستور متنی یکسان است.
صفحه‌ها: ساعت (۴ قالب آماده/ارقام/بیو/بازگردانی) • AFK • پاسخ خودکار • قوانین اگر-آنگاه • آنتی‌اسپم •
نوت‌ها • یادآورها • AI (تست/وضعیت/ریست حافظه) • آمار • تنظیمات (زبان/حذف دستور) • سلامت • راهنما.
callback_query ها هم در getUpdates مدیریت و با answerCallbackQuery پاسخ داده می‌شوند؛
پس از هر اکشن صفحه با وضعیت تازه دوباره رندر می‌شود (editMessageText با fallback پیام جدید).
خروجی دستورات با parse_mode=Markdown ارسال می‌شود (fallback خودکار به متن ساده).
